# Project Feedback Video Script (about 90 seconds)

Hello, I am [MARIA JONA G], and this is my EduPro Instructor Performance and Course Quality Evaluation project.

The purpose of this project is to help an online-learning platform evaluate teaching quality consistently. Instead of relying only on subjective opinions, the dashboard brings together teacher profiles, course ratings, and transaction records to identify patterns in instructor effectiveness and course quality.

I built the dashboard in Streamlit. It includes an instructor-performance leaderboard, an experience-versus-rating analysis, a course-quality heatmap by category and level, and expertise-wise performance comparisons. Users can filter the results by expertise, course category, level, rating range, and enrollment volume.

One of my key learnings was that ratings need context. A high rating from a very small number of courses or enrollments should not be interpreted in the same way as a sustained rating across many courses. I therefore included enrollment measures and a rating-consistency indicator in the analysis.

I also learned the importance of responsible analytics. The dashboard is intended to support coaching and course improvement, not automated high-stakes decisions about instructors. Findings should always be reviewed with sample size, course context, and learner feedback in mind.

Thank you for reviewing my project.
